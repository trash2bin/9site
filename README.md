# Ivan's Little Web

Персональный сайт с ретро-оформлением Web 1.0, страницей по макету и фотоальбомом с умным фильтром.

![Главная страница сайта](docs/preview.webp)

## Запуск

Нужен Go 1.24 или новее.

```bash
go run .
```

Сайт откроется по адресу <http://localhost:8080>. Остановить сервер: `Ctrl+C`.

## Страницы

- `/` — главная страница.
- `/maket` — отдельная страница, свёрстанная по макету.
- `/catalog` — фотоальбом с фильтрами по разделу, типу файла и ориентации. Недоступные варианты автоматически отключаются; печатный вид включается без перезагрузки.
- `/studio` — витрина закрытого раздела: открыта всем, показывает движ для авторизованных; вход и регистрация — во всплывающем окне.
- `/vault` — закрытый раздел: без входа сервер перенаправляет на окно авторизации (проверяется и тестами, и на деплое).

## Разработка

Node.js нужен для проверок и сборки TypeScript в один компактный браузерный скрипт, но не для запуска сайта.

```bash
npm install
npm run lint
```

После изменений в `src/` проверьте типы и пересоберите production-скрипт:

```bash
npm run build:ts
```

Основные команды:

| Команда                | Назначение                                       |
| ---------------------- | ------------------------------------------------ |
| `npm run format`       | Форматировать файлы проекта                      |
| `npm run format:check` | Проверить форматирование                         |
| `npm run lint:css`     | Проверить CSS                                    |
| `npm run lint:ts`      | Проверить типы TypeScript                        |
| `npm run build:ts`     | Проверить типы и собрать компактный JS-бандл     |
| `npm run lint:go`      | Проверить Go-код                                 |
| `npm run size`         | Проверить размер главной страницы и общих стилей |
| `npm run lint`         | Запустить основные проверки                      |

## Устройство проекта

- `public/` — HTML-страницы, стили, клиентские модули и изображения.
- `src/` — TypeScript-логика фотоальбома: данные, критерии, фильтрация и отображение.
- `public/js/main.js` — минифицированный production-бандл фотоальбома; генерируется командой `npm run build:ts`.
- `main.go` — HTTP-сервер для локального запуска и раздачи сайта.
- `auth/` — закрытый раздел: регистрация, авторизация, сессии и сброс пароля (Go + SQLite).
- `scripts/` — вспомогательные скрипты.

## Закрытый раздел и авторизация

Данные авторизации лежат в каталоге `DATA_DIR` (по умолчанию `var/`, в проде
`/var/lib/9site`): база `auth.db`, аватары `avatars/`, исходящие письма
`outbox/`. Пароли хранятся bcrypt-хэшем, сессия — cookie с случайным токеном
(в базе только его sha256), все запросы к базе параметризованы, вывод
экранируется через `html/template`.

Восстановление пароля шлёт письмо со ссылкой `/reset?token=…`. Если SMTP не
настроен, письмо сохраняется в `DATA_DIR/outbox/` и ссылка показывается на
экране. Переменные окружения:

| Переменная               | Назначение                                           |
| ------------------------ | ---------------------------------------------------- |
| `DATA_DIR`               | каталог базы, аватаров и писем (по умолчанию `var/`) |
| `BASE_URL`               | внешний адрес сайта для ссылок в письмах             |
| `SMTP_HOST`, `SMTP_PORT` | почтовый сервер (порт 465 — сразу TLS)               |
| `SMTP_USER`, `SMTP_PASS` | учётная запись SMTP                                  |
| `SMTP_FROM`              | адрес отправителя писем                              |

Проверка всего модуля: `go test ./auth/` (регистрация, вход, закрытый раздел,
выход, смена данных, сброс пароля, SQL-инъекции, XSS, аватары).
